Device Management

General Description

This section consists of several management entities:

  • Device Control - controls the local device
  • Device Discovery - manages inquiries, discover database
  • ACL Channels - manages LE ACL connections
  • Security - manages all security functionality

Event to notify change in the device RPA (Resolvable Private Address)

This event is triggered when the device's Resolvable Private Address (RPA) changes. The latest RPA generated by the stack can be found in the wiced_bt_ble_device_addr_update_t::bdaddr field of the wiced_bt_management_evt_data_t::ble_addr_update_event structure.

Applications using extended advertisements can utilize this event to update the random address and advertisement data on the adv_handle using the following APIs:

  1. wiced_ble_ext_adv_set_random_address to update the advertising address for the specific advertising handle
  2. wiced_ble_ext_adv_set_adv_data to update the advertisement data
  3. wiced_ble_ext_adv_set_scan_rsp_data to update the scan response data

Similarly, applications using legacy advertisements can use this event to update the advertisement data and scan response data on the adv_handle using the following APIs:

  1. wiced_bt_ble_set_raw_advertisement_data or wiced_bt_ble_set_legacy_adv_data to update the advertisement data
  2. wiced_bt_ble_set_raw_scan_response_data to update the scan response data
Note
This event is only generated when the application is configured to generate a private address on the host processor using wiced_ble_init_host_private_addr_generation. This is typically invoked in the porting layer of the stack.
