Mesh Core Library API
LE Mesh

General Description

Mesh Core library of the AIROC BTSDK provide a simple method for an application to integrate Bluetooth Mesh functionality.

Mesh Core library of the AIROC BTSDK provides access to the LE Mesh Core. Typically application will not access LE Mesh Core directly but through the LE Mesh Models library functions.
